# 教職員管理外掛文檔索引

此目錄包含關於教職員管理外掛的所有文檔資料。

## 目錄

### 用戶文檔
- [README.md](./README.md) - 外掛主要說明文件，包含功能、安裝和使用方法
- [WordPressPluginDevelopmentTutorial.md](./WordPressPluginDevelopmentTutorial.md) - 使用此外掛作為案例的WordPress外掛開發教學

### 開發者文檔
- [CHANGELOG.md](./CHANGELOG.md) - 版本更新歷史記錄
- [PUBLISHING.md](./PUBLISHING.md) - 外掛發布指南
- [release-plan.md](./release-plan.md) - 外掛發布、維護和更新計劃

## 文檔維護

這些文檔應當隨著外掛的更新而持續更新。每次發布新版本時，請確保：

1. 更新 `CHANGELOG.md` 記錄新版本的變更
2. 檢查 `README.md` 確保信息保持最新
3. 如需要，更新教學文檔以反映新功能

## 文檔結構

```
documents/
├── README.md               # 外掛主要說明
├── CHANGELOG.md            # 版本歷史
├── PUBLISHING.md           # 發布指南
├── release-plan.md         # 發布計劃
├── WordPressPluginDevelopmentTutorial.md  # 開發教學
└── index.md                # 本文檔（索引）
```
