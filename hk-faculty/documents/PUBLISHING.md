# 教職員管理外掛發佈指南

本文檔提供如何發佈、維護和更新「教職員管理」外掛的詳細說明。

## 發佈流程

### 1. 準備發佈

1. **檢查代碼**
   ```bash
   # 確保所有文件都已添加到版本控制
   git status
   
   # 如有未跟踪的文件，添加它們
   git add .
   
   # 提交更改
   git commit -m "準備發佈 x.y.z 版本"
   ```

2. **更新版本號**
   - 更新 `hk-faculty.php` 中的版本號
   - 更新 `README.md` 中的版本信息
   - 更新 `CHANGELOG.md` 添加新版本信息

3. **運行打包腳本**
   ```bash
   php build.php
   ```
   打包後的文件將位於 `build` 目錄下

### 2. 測試發佈包

1. **在測試環境中安裝**
   - 使用乾淨的 WordPress 安裝
   - 上傳並啟用外掛
   - 測試所有功能

2. **多網站測試**
   - 在 WordPress 多網站環境中測試
   - 確保網路管理功能正常

### 3. 正式發佈

#### 3.1 私有發佈

1. **準備發佈說明**
   - 撰寫版本亮點
   - 列出新功能和修復的問題
   - 提供安裝和更新說明

2. **分發外掛**
   - 通過電子郵件發送
   - 上傳到私有服務器
   - 或使用自定義更新系統

#### 3.2 WordPress.org 發佈（如適用）

1. **準備 SVN 提交**
   ```bash
   # 檢出 SVN 存儲庫（首次使用）
   svn co https://plugins.svn.wordpress.org/hk-faculty/ svn-hk-faculty
   
   # 複製新版本文件到 SVN 目錄
   cp -R build/temp/* svn-hk-faculty/trunk/
   
   # 創建標籤
   svn cp svn-hk-faculty/trunk svn-hk-faculty/tags/x.y.z
   
   # 添加新文件
   cd svn-hk-faculty
   svn add --force trunk/*
   svn add --force tags/x.y.z/*
   
   # 提交更改
   svn ci -m "釋出 x.y.z 版本"
   ```

2. **更新 WordPress.org 外掛頁面**
   - 更新描述和常見問題
   - 上傳新截圖（如有變更）
   - 測試外掛安裝和更新

## 維護計劃

### 1. 日常維護

- 每月檢查兼容性問題
- 監控用戶反饋
- 跟踪錯誤報告
- 更新與最新 WordPress 版本的兼容性

### 2. 數據收集

- 收集使用統計（如適用）
- 分析常見問題
- 獲取用戶需求

### 3. 安全維護

- 定期進行安全審計
- 監控依賴項更新
- 快速回應安全問題報告

## 更新流程

### 1. 計劃更新

- 根據用戶反饋和需求收集創建功能列表
- 安排修復已知問題
- 設定更新時間表

### 2. 開發更新

- 在開發分支上實施更改
- 進行代碼審查
- 執行全面測試

### 3. 發布更新

- 按照發布流程操作
- 通知用戶更新可用
- 監控初始安裝情況

## 版本號策略

我們遵循語義化版本規範 (SemVer):

- **主版本號 (x.0.0)**: 不兼容的 API 更改
- **次版本號 (0.x.0)**: 向後兼容的功能新增
- **修訂號 (0.0.x)**: 向後兼容的問題修復
