# 教職員管理外掛

這是一個 WordPress 外掛，用於管理教職員資料，包括教師和職員。

## 功能特點

- 教師資料管理：包括姓名、照片、學歷、職位、工作經驗、專長領域、聯絡資訊等
- 職員資料管理：包括姓名、照片、職稱、工作職掌、聯絡資訊等
- 教師類型分類：支援專任教師和兼任教師的分類
- 多種顯示方式：支援列表和單一資訊顯示
- 響應式設計：適應不同螢幕尺寸
- 自訂顯示欄位：可控制顯示的欄位和排列方式
- 多列顯示：可設定每列顯示的教職員數量
- 照片位置自適應：根據列數自動調整照片位置

## 安裝方法

1. 下載外掛壓縮檔
2. 在 WordPress 後台選擇「外掛」>「安裝外掛」
3. 點擊「上傳外掛」按鈕
4. 選擇下載的壓縮檔並安裝
5. 啟用外掛

## 使用方法

### 教師管理

#### 新增教師

1. 在 WordPress 後台選擇「教職員管理」>「教師管理」
2. 點擊「新增教師」按鈕
3. 填寫教師資料，包括：
   - 姓名（標題欄位）
   - 教師類型（專任/兼任）
   - 學歷
   - 現任職位
   - 工作經驗
   - 專長領域
   - 電子郵件
   - 分機號碼
   - 辦公室位置
4. 上傳教師照片（特色圖片）
5. 點擊「發佈」按鈕保存

#### 顯示教師列表

使用 shortcode `[teacher_list]` 在頁面或文章中顯示教師列表。

##### 參數說明

| 參數 | 說明 | 預設值 | 可用值 |
|------|------|--------|--------|
| limit | 顯示數量 | 10 | 任意正整數 |
| orderby | 排序依據 | title | title, date, rand |
| order | 排序方式 | ASC | ASC, DESC |
| type | 教師類型篩選 | 空（顯示全部） | full_time（專任）, part_time（兼任） |
| show_type | 是否顯示教師類型標籤 | true | true, false |
| columns | 每列顯示的教師數量 | 1 | 1-6 |

##### 範例

```
[teacher_list limit="5" type="full_time" columns="3"]
```

顯示 5 位專任教師，每列顯示 3 位。

### 職員管理

#### 新增職員

1. 在 WordPress 後台選擇「教職員管理」>「職員管理」
2. 點擊「新增職員」按鈕
3. 填寫職員資料，包括：
   - 姓名（標題欄位）
   - 職稱
   - 工作職掌
   - 電子郵件
   - 電話/分機
4. 上傳職員照片（特色圖片）
5. 點擊「發佈」按鈕保存

#### 顯示職員列表

使用 shortcode `[staff_list]` 在頁面或文章中顯示職員列表。

##### 參數說明

| 參數 | 說明 | 預設值 | 可用值 |
|------|------|--------|--------|
| limit | 顯示數量 | 10 | 任意正整數 |
| orderby | 排序依據 | title | title, date, rand |
| order | 排序方式 | ASC | ASC, DESC |
| columns | 每列顯示的職員數量 | 1 | 1-6 |

##### 範例

```
[staff_list limit="5" columns="3"]
```

顯示 5 位職員，每列顯示 3 位。

## 響應式設計說明

本外掛採用響應式設計，會根據不同的螢幕尺寸自動調整顯示方式：

- 大螢幕（>1200px）：顯示指定的列數（最多 6 列）
- 中等螢幕（992px-1200px）：最多顯示 3 列
- 平板（768px-992px）：最多顯示 2 列
- 手機（<768px）：始終顯示 1 列
