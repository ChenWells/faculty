# 房東管理系統詳細需求規格書

## 1. 專案概述

### 1.1 專案目標
建立一個完整的房東管理系統，主要功能包括電費計算、合約管理、收租管理、LINE通知服務，並支援多位管理者協作，資料同步至Google Sheets。

### 1.2 目標用戶
- 主要用戶：房屋管理者（房東）
- 次要用戶：租客（僅查看權限）

## 2. 功能需求詳細規格

### 2.1 電費計算模組 (REQ-001)

#### 2.1.1 電表度數輸入功能 (REQ-001-01)
**需求描述**：系統必須支援輸入電表度數，並自動計算電費。

**功能規格**：
- 支援手動輸入電表度數
- 支援拍照識別電表度數（OCR功能）
- 記錄輸入時間和操作人員
- 支援私電和公電度數分別輸入
- 提供度數驗證（防止異常數值）

**輸入參數**：
- 電表編號（必填）
- 私電度數（必填，數值型）
- 公電度數（必填，數值型）
- 抄表日期（必填，日期型）
- 備註（選填，文字型）

**輸出結果**：
- 電費計算結果
- 計算明細
- 歷史對比數據

#### 2.1.2 電費計算方式 (REQ-001-02)

**方式一：固定電價計算 (REQ-001-02-01)**
- **計算公式**：電費 = (私電度數 + 公電度數) × 固定單價
- **設定參數**：固定單價（元/度）
- **適用場景**：電費單價固定的情況

**方式二：平均電價計算 (REQ-001-02-02)**
- **計算公式**：
  - 平均每度電費 = 前期總電費 ÷ 前期總用電度數
  - 電費 = (私電度數 + 公電度數) × 平均每度電費
- **設定參數**：前期電費記錄
- **適用場景**：電費單價浮動的情況

**方式三：混合電價計算 (REQ-001-02-03)**
- **計算公式**：
  - 平均每度電費 = 前期總電費 ÷ 前期總用電度數
  - 電費 = 私電度數 × 平均每度電費 + 公電度數 × 固定每度電費
- **設定參數**：固定公電單價、前期電費記錄
- **適用場景**：私電浮動，公電固定的情況

#### 2.1.3 前期電費輸入與平均計算 (REQ-001-03)
**需求描述**：系統必須支援輸入前期電費，並自動計算平均每度電費。

**功能規格**：
- 支援輸入前期電費總金額
- 支援輸入前期總用電度數
- 自動計算平均每度電費
- 支援多期電費記錄管理
- 提供電費趨勢分析

**計算邏輯**：
```
平均每度電費 = Σ(各期電費總額) ÷ Σ(各期總用電度數)
```

### 2.2 合約管理模組 (REQ-002)

#### 2.2.1 合約建立功能 (REQ-002-01)
**需求描述**：系統必須支援建立完整的租賃合約，包含所有必要資訊。

**合約必填資訊**：
- **基本資訊**：
  - 合約編號（系統自動生成）
  - 簽約日期
  - 合約起訖日期
  - 房屋地址
  - 租客資訊
- **費用設定**：
  - 月租金金額
  - 押金金額
  - 電費計算方式（選擇REQ-001-02中的三種方式之一）
  - 其他費用項目（管理費、清潔費、網路費等）
- **付款條件**：
  - 付款日期（每月幾號）
  - 付款方式
  - 逾期罰則
  - 付款帳戶資訊

**合約狀態管理**：
- 草稿
- 生效中
- 到期
- 終止
- 續約

#### 2.2.2 合約管理功能 (REQ-002-02)
- 合約CRUD操作
- 合約狀態追蹤
- 合約範本管理
- 合約歷史記錄
- 合約到期提醒

### 2.3 費用計算與收租管理模組 (REQ-003)

#### 2.3.1 月度費用計算 (REQ-003-01)
**需求描述**：系統必須自動計算每月應收費用總額。

**計算公式**：
```
月度應收費用 = 月租金 + 電費 + 其他費用 - 折扣金額
```

**計算流程**：
1. 系統自動觸發月度費用計算
2. 根據合約設定計算各項費用
3. 生成費用明細單
4. 更新收租記錄

#### 2.3.2 收租流程管理 (REQ-003-02)
**收租流程**：
1. 系統自動計算月度費用
2. 發送LINE收租通知
3. 租客繳費
4. 記錄繳費情況
5. 發送繳費確認通知
6. 更新財務記錄

**繳費記錄功能**：
- 記錄繳費日期
- 記錄繳費金額
- 記錄繳費方式
- 記錄操作人員
- 支援部分繳費
- 支援逾期繳費

### 2.4 LINE通知服務模組 (REQ-004)

#### 2.4.1 收租通知功能 (REQ-004-01)
**需求描述**：系統必須透過LINE自動發送收租通知。

**通知內容**：
- 租客姓名
- 房屋地址
- 應繳費用明細
- 繳費截止日期
- 繳費方式說明
- 聯絡方式

**通知時機**：
- 每月固定日期自動發送
- 可設定提前提醒天數
- 支援逾期提醒

#### 2.4.2 繳費確認通知 (REQ-004-02)
**需求描述**：房客繳費後，系統必須自動發送確認通知到LINE群組。

**通知內容**：
- 租客姓名
- 房屋地址
- 繳費金額
- 繳費日期
- 繳費方式
- 確認人員

**通知對象**：
- LINE群組所有成員
- 相關管理者

#### 2.4.3 通知設定功能 (REQ-004-03)
- LINE群組管理
- 通知模板管理
- 通知時機設定
- 通知對象設定

### 2.5 多管理者權限模組 (REQ-005)

#### 2.5.1 多管理者支援 (REQ-005-01)
**需求描述**：系統必須支援1到多位房屋管理者，且具有相同權限。

**權限設定**：
- 所有管理者具有完整系統存取權
- 支援同時操作
- 操作衝突處理機制
- 操作記錄追蹤

**管理者功能**：
- 合約管理
- 費用計算
- 收租管理
- 電費記錄
- 系統設定

#### 2.5.2 協作功能 (REQ-005-02)
- 操作通知
- 工作分配
- 溝通記錄
- 任務追蹤

### 2.6 Google Sheets整合模組 (REQ-006)

#### 2.6.1 資料同步功能 (REQ-006-01)
**需求描述**：系統資料必須自動同步至Google Sheets。

**同步內容**：
- 房屋基本資料
- 租客資料
- 合約資料
- 電費記錄
- 收租記錄
- 財務報表

**同步機制**：
- 即時同步（資料變更時）
- 定期同步（每日/每週）
- 手動同步
- 同步狀態監控

#### 2.6.2 Google Sheets管理 (REQ-006-02)
- 試算表結構設計
- 存取權限管理
- 資料備份
- 報表匯出

## 3. 非功能需求

### 3.1 效能需求
- 系統響應時間：< 3秒
- 同時在線用戶：100人
- 資料處理能力：1000筆/分鐘

### 3.2 安全需求
- 資料加密存儲
- HTTPS傳輸
- 用戶認證授權
- 操作日誌記錄

### 3.3 可用性需求
- 系統可用性：99.5%
- 資料備份：每日
- 災難恢復：< 4小時

### 3.4 相容性需求
- 支援主流瀏覽器
- 支援手機和平板
- 支援LINE官方帳號

## 4. 系統限制

### 4.1 技術限制
- 需要LINE官方帳號
- 需要Google Sheets API權限
- 需要穩定的網路連接

### 4.2 業務限制
- 電費計算方式必須在合約中明確規定
- 通知發送需要符合LINE使用規範
- 資料同步需要Google帳號權限

## 5. 驗收標準

### 5.1 功能驗收
- 所有功能需求必須100%實現
- 電費計算準確性必須100%
- LINE通知發送成功率 > 95%
- 資料同步準確性必須100%

### 5.2 效能驗收
- 系統響應時間符合要求
- 同時在線用戶數符合要求
- 資料處理能力符合要求

### 5.3 安全驗收
- 通過安全測試
- 資料加密驗證
- 權限控制驗證

## 6. 專案時程

### 6.1 開發階段
- **第一階段**：基礎架構和用戶管理（2週）
- **第二階段**：合約管理和電費計算（3週）
- **第三階段**：收租管理和LINE通知（2週）
- **第四階段**：Google Sheets整合（1週）
- **第五階段**：測試和優化（2週）
