# 房東管理系統需求描述

## 1. 系統概述

房東管理系統是一個專為房東設計的數位化工具，旨在簡化租客管理、租金合約處理、費用計算、通知流程、出租物件管理、應收款項管理、租客問題反應與解決、支出管理、租客入住與退租點交，以及仲介帶看管理。系統將提供租客資料管理、合約管理、每月費用計算（包含電費、水費、網路費等）、透過LINE群組自動發送租金通知、出租物件管理、應收款項處理、租客問題管理、支出記錄、入住與退租點交，以及仲介帶看與成交數據統計功能。

- **目標用戶**：房東或物業管理者
- **核心功能**：租客管理、合約管理、費用計算、自動通知、使用者管理、出租物件管理、應收款項管理、租客問題反應與解決、支出管理、租客入住與退租點交、仲介帶看管理

## 2. 功能需求

### 2.1 使用者管理

- **使用者角色**：
  - **系統管理者**：負責管理房東帳號，擁有最高權限。
  - **房東**：管理租房管理員帳號、房客帳號、出租物件、應收款項、租客問題、支出、入住/退租點交及仲介帶看，可自行擔任租房管理員角色（無需額外建立租房管理員帳號）。
  - **租房管理員**：由房東授權，負責管理房客帳號、出租物件、應收款項、租客問題、支出、入住/退租點交、仲介帶看及相關租賃業務。
  - **房客**：查看個人合約、費用明細、接收通知、提交問題反應及參與入住/退租點交。
  - **仲介**：記錄帶看活動、查看分配的出租物件及提交成交資料，無權管理其他功能。
- **帳號管理功能**：
  - 系統管理者可新增、編輯、停用或刪除房東帳號。
  - 房東可新增、編輯、停用或刪除租房管理員及仲介帳號，或自行擔任租房管理員角色。
  - 房東或租房管理員可新增、編輯、停用或刪除房客帳號。
  - 房客帳號僅限查看個人相關資料、提交問題反應及參與入住/退租點交。
  - 仲介帳號僅限記錄帶看、查看分配的出租物件及提交成交資料。
- **權限控制**：
  - 系統管理者：可訪問所有功能與資料。
  - 房東：可訪問其管理的租房管理員、房客資料、合約、費用、出租物件、應收款項、租客問題、支出、入住/退租點交及仲介帶看相關功能。
  - 租房管理員：可訪問房東授權的房客資料、合約、費用、出租物件、應收款項、租客問題、支出、入住/退租點交及仲介帶看相關功能。
  - 房客：僅可查看個人合約、費用明細、通知記錄、提交/查看問題反應及參與入住/退租點交。
  - 仲介：僅可訪問分配的出租物件、記錄帶看活動及提交成交資料。

### 2.2 出租物件管理

- **出租物件類型**：
  - 透天
  - 公寓
  - 獨立套房
  - 分租套房（屬於整棟或整層公寓）
- **出租物件資料**：
  - 物件名稱或編號
  - 物件類型（透天/公寓/獨立套房/分租套房）
  - 地址
  - 總樓層數（若適用）
  - 物件面積（平方公尺或坪）
  - 房間數量（若適用）
  - 設施（例：空調、家具、停車位）
  - 當前租賃狀態（已出租/空置）
  - 關聯的房客、合約、支出、入住/退租點交及仲介帶看記錄
- **管理功能**：
  - 房東或租房管理員可新增、編輯、刪除或查詢出租物件。
  - 支持物件與房客、合約、支出、入住/退租點交及仲介帶看的關聯管理（例：指定某房客入住某物件或記錄某物件的帶看活動）。
  - 物件清單匯出功能（格式：CSV/Excel）。
  - 支持篩選與搜尋（如按物件類型、租賃狀態或地址搜尋）。
- **分租套房管理**：
  - 分租套房需關聯至其所屬的整棟或整層公寓。
  - 可單獨管理分租套房的房客、合約、費用、支出、入住/退租點交及仲介帶看。

### 2.3 租客管理

- 租客基本資料：姓名、聯絡電話、電子郵件、身分證號、緊急聯絡人
- 租客資料的增刪改查功能
- 租客資料匯出功能（格式：CSV/Excel）
- 租客資料與合約、出租物件、問題反應、應收款項、入住/退租點交及仲介成交關聯

### 2.4 租金合約管理

- 合約資料：租金金額、合約起訖日期、電費計算方式（每度單價）、水費（固定或按用量）、網路費、其他費用（例：管理費、設備租賃費、清潔費）、關聯的出租物件、仲介資訊（若適用）
- 合約模板管理：支持自訂合約模板
- 合約到期提醒：提前30天通知房東
- 合約續簽功能：快速複製現有合約並修改

### 2.5 費用計算與應收款項管理

- **每月費用計算**：
  - 每月電表度數輸入：支持手動輸入或批量上傳（CSV格式），可按出租物件分別輸入。
  - 電費計算：根據合約設定的每度單價計算。
  - 其他費用計算：水費（固定或按用量）、網路費、清潔費、管理費等。
  - 費用明細生成：每月為每位租客生成詳細費用清單（租金+各項費用），包含關聯的出租物件資訊。
  - 費用清單匯出：支持PDF/Excel格式。
- **應收款項管理**：
  - 房東或租房管理員可每月處理應收款項，包括租金、電費、水費、清潔費、網路費、管理費等。
  - 應收款項狀態追蹤：標記為未繳、部分繳款或已繳清。
  - 應收款項記錄：記錄每筆應收款項的金額、到期日、繳款狀態及繳款日期。
  - 逾期提醒：自動標記逾期未繳款項，並支持透過LINE通知房客。
  - 應收款項報表：生成每月應收款項總覽（按租客或出租物件），支持篩選（未繳/已繳/逾期）及匯出（CSV/Excel）。
  - 手動調整功能：房東或租房管理員可手動調整應收款項（例：減免費用或新增臨時費用）。

### 2.6 租客問題反應與解決

- **問題反應功能**：
  - 房客可透過系統提交問題反應（如設備故障、環境問題或其他租賃相關問題）。
  - 問題資料：問題描述、提交時間、關聯的出租物件、問題類型（例：水電、空調、噪音、清潔）、照片或檔案上傳（支持JPG/PNG/PDF）。
  - 房客可查看自己提交的問題狀態及處理進度。
- **問題管理功能**：
  - 房東或租房管理員可查看、處理及更新問題狀態（例：待處理、處理中、已解決）。
  - 支持問題指派：房東可將問題指派給租房管理員處理。
  - 問題解決記錄：記錄處理過程、解決方案、完成時間及相關支出（例：維修費用）。
  - 問題篩選與搜尋：支持按問題狀態、租客、出租物件或問題類型篩選與搜尋。
  - 問題匯出功能：支持將問題記錄匯出為CSV/Excel格式。
- **通知整合**：
  - 問題提交後，自動透過LINE通知房東或租房管理員。
  - 問題狀態更新時，自動通知相關房客（如問題已解決）。
  - 支持自訂問題通知模板（例：包含問題描述、處理狀態、預計完成時間）。

### 2.7 支出管理

- **支出類型**：
  - 電費（公共區域或非租客負擔部分）
  - 水費（公共區域或非租客負擔部分）
  - 管理費（物業管理公司費用）
  - 清潔費（公共區域清潔或專業清潔服務）
  - 維修費用（設備維修或物件維護）
  - 設備更換（例：更換空調、熱水器、家具）
  - 仲介費用（帶看或成交佣金）
  - 其他支出（例：稅費、行政費用）
- **支出記錄功能**：
  - 房東或租房管理員可記錄每筆支出，包括金額、日期、支出類型、關聯的出租物件（若適用）、收據或證明檔案上傳（支持JPG/PNG/PDF）。
  - 支持批量上傳支出記錄（CSV格式）。
  - 支出與問題反應或仲介成交關聯：若支出因解決租客問題（如維修費用）或仲介成交（如佣金）而產生，可關聯至對應記錄。
- **支出管理功能**：
  - 支持支出資料的增刪改查。
  - 支出篩選與搜尋：按支出類型、日期範圍、出租物件或金額篩選與搜尋。
  - 支出報表：生成每月/年度支出總覽（按類型或物件），支持匯出（CSV/Excel）。
  - 支出分析：提供支出趨勢圖表（例：按類型或物件的支出分佈）。
- **支出審核**：
  - 房東可審核租房管理員錄入的支出，確保準確性。
  - 支持支出狀態標記（待審核/已審核/已支付）。

### 2.8 租客入住與退租點交

- **入住點交功能**：
  - 房東或租房管理員可創建入住點交清單，記錄出租物件的狀況（例：牆壁、地板、家具、電器、門窗等）。
  - 點交資料：點交日期、房客姓名、關聯的出租物件、物品清單、物品狀況描述、照片或影片上傳（支持JPG/PNG/MP4）、水電表讀數、雙方簽名（電子簽名或上傳簽名檔案）、仲介資訊（若適用）。
  - 房客可查看並確認入住點交清單，提交意見或補充照片。
  - 點交完成後生成 aquellos入住點交報告（PDF格式），供房東、租房管理員、房客及仲介（若適用）存檔。
- **退租點交功能**：
  - 房東或租房管理員可創建退租點交清單，與入住點交清單比對，檢查物件狀況。
  - 點交資料：點交日期、房客姓名、關聯的出租物件、物品清單、物品狀況描述（包含損壞或遺失情況）、照片或影片上傳、水電表讀數、退租費用結算（例：損壞賠償、未繳費用）、雙方簽名、仲介資訊（若適用）。
  - 房客可查看並確認退租點交清單，提交意見或補充照片。
  - 點交完成後生成退租點交報告（PDF格式），包含費用結算詳情，供房東、租房管理員、房客及仲介（若適用）存檔。
- **點交管理功能**：
  - 支持點交記錄的查詢與篩選（按房客、出租物件、仲介或日期）。
  - 點交記錄與合約、應收款項、支出及仲介成交關聯（例：退租損壞賠償記錄為應收款項，維修費用記錄為支出）。
  - 點交記錄匯出功能（CSV/Excel格式）。
  - 支持點交狀態追蹤（待確認/已確認/有爭議）。
- **通知整合**：
  - 入住/退租點交清單創建後，自動透過LINE通知房客及仲介（若適用）確認。
  - 點交狀態更新或完成時，自動通知相關房客、房東/租房管理員及仲介。
  - 支持自訂點交通知模板（例：包含點交日期、物件名稱、確認期限）。

### 2.9 仲介帶看管理

- **仲介管理功能**：
  - 房東或租房管理員可新增、編輯或刪除仲介資料（姓名、聯絡電話、電子郵件、公司名稱）。
  - 支持將出租物件分配給特定仲介，仲介僅可查看及管理分配的物件。
  - 仲介資料與帶看及成交記錄關聯。
- **帶看記錄功能**：
  - 仲介可記錄每次帶看活動，包括帶看日期、時間、出租物件、潛在租客姓名、帶看結果（感興趣/無興趣/待定）、備註、照片或檔案上傳（支持JPG/PNG/PDF）。
  - 房東或租房管理員可查看及管理帶看記錄，確保活動進度透明。
  - 支持帶看狀態追蹤（待審核/已確認/已取消）。
- **成交管理功能**：
  - 仲介可提交成交資料，包括成交日期、房客姓名、合約詳情、佣金金額、相關檔案上傳（支持JPG/PNG/PDF）。
  - 房東或租房管理員可審核成交資料，確認後更新出租物件狀態（空置→已出租）及記錄佣金支出。
  - 成交記錄與合約、入住點交及應收款項關聯。
- **數據統計與分析**：
  - 統計仲介帶看數據：按仲介、出租物件或時間段計算帶看次數、成功率（成交/帶看比例）。
  - 統計成交時間：計算從首次帶看至成交的平均時間（按物件或仲介）。
  - 報表功能：生成仲介帶看及成交報表（按仲介、物件或時間），支持匯出（CSV/Excel）。
  - 圖表分析：提供帶看趨勢圖、成交率圖表及成交時間分佈圖。
- **通知整合**：
  - 帶看記錄新增或更新時，自動透過LINE通知房東或租房管理員。
  - 成交資料提交或審核完成時，自動通知仲介及房東/租房管理員。
  - 支持自訂帶看/成交通知模板（例：包含帶看時間、物件名稱、成交詳情）。

### 2.10 自動通知

- LINE群組整合：系統與租客的LINE群組連動
- 每月租金及費用通知：每月初自動發送費用明細至租客LINE群組，包含關聯的出租物件資訊及應收款項詳情
- 逾期通知：針對逾期未繳款項，自動發送提醒通知
- 問題相關通知：問題提交、狀態更新或解決時發送通知
- 支出相關通知：新支出錄入或審核完成時通知房東（若由租房管理員錄入）
- 入住/退租點交通知：點交清單創建、狀態更新或完成時發送通知
- 仲介相關通知：帶看記錄新增/更新、成交資料提交/審核時發送通知
- 通知模板：支持自訂通知內容（例：包含租客姓名、費用明細、繳費期限、出租物件名稱、問題狀態、支出詳情、點交資訊、帶看/成交詳情）
- 通知記錄：保存每次通知的發送時間與內容

## 3. 非功能需求

- **安全性**：用戶身份驗證（支援電子郵件/密碼或第三方登入，如Google），確保各角色僅能訪問其權限範圍內的資料
- **資料加密**：租客資料、合約資料、使用者帳號資料、出租物件資料、應收款項資料、問題反應資料、支出資料、點交資料及仲介帶看資料需加密儲存
- **多語言支持**：繁體中文為主，未來可擴展英文
- **響應式設計**：支持桌面與行動裝置（手機/平板）
- **性能**：系統需支持至少100位租客資料、相應的使用者帳號、100個出租物件、相應的應收款項、問題反應、支出、點交及仲介帶看記錄，費用計算、通知發送、問題處理、支出處理、點交處理及帶看處理需在5秒內完成
- **可擴展性**：未來可整合支付系統（如銀行轉帳或第三方支付）

## 4. 使用者介面需求

- **儀表板**不同角色：
  - 系統管理者：顯示房東總數、帳號狀態概覽
  - 房東/租房管理員：顯示租客總數、出租物件總數（已出租/空置）、即將到期合約、未繳費租客數量、應收款項總額（未繳/逾期）、待處理問題數量、近期支出總額、待確認點交數量、仲介帶看次數及成交率
  - 房客：顯示個人合約狀態、費用明細、通知、問題反應狀態及點交狀態
  - 仲介：顯示分配的出租物件、帶看次數、成交數量及待審核記錄
- **使用者管理頁面**：
  - 系統管理者：房東帳號清單，支持篩選與搜尋
  - 房東：租房管理員、房客及仲介帳號清單，支持篩選與搜尋
- **出租物件管理頁面**：表格顯示出租物件清單，支持篩選與搜尋（按物件類型、租賃狀態或地址），顯示關聯的支出、點交及仲介帶看記錄
- **租客管理頁面**：表格顯示租客清單，支持篩選與搜尋，顯示關聯的出租物件、應收款項狀態、問題反應、支出、點交及仲介成交記錄
- **合約管理頁面**：顯示合約詳情與狀態（有效/即將到期/已到期），包含關聯的出租物件及仲介資訊
- **費用計算與應收款項頁面**：支持按出租物件批量輸入電表度數，顯示費用計算結果及應收款項狀態，允許手動調整應收款項
- **問題反應與解決頁面**：顯示問題清單，支持篩選與搜尋（按狀態、租客、物件或類型），允許更新問題狀態及記錄解決方案，顯示關聯的支出
- **支出管理頁面**：顯示支出清單，支持篩選與搜尋（按類型、日期、物件或金額），允許新增/編輯支出、審核狀態及查看報表/趨勢圖表
- **入住與退租點交頁面**：顯示點交清單，支持篩選與搜尋（按房客、物件、仲介或日期），允許創建/編輯點交清單、確認狀態及生成報告
- **仲介帶看管理頁面**：顯示仲介清單及帶看/成交記錄，支持篩選與搜尋（按仲介、物件、日期或狀態），允許錄入/審核帶看及成交資料，顯示統計報表及圖表
- **通知管理頁面**：顯示通知記錄與發送狀態，包含關聯的出租物件、應收款項、問題反應、支出、點交及仲介帶看資訊

## 5. 整合需求

- **LINE API**：用於發送通知至租客LINE群組（費用、逾期、問題、支出、點交、仲介相關通知）
- **雲端儲存**：用於儲存租客資料、合約、費用清單、使用者帳號資料、出租物件資料、應收款項資料、問題反應資料、支出資料、點交資料及仲介帶看資料（如AWS S3或Google Cloud Storage）
- **匯出工具**：支援CSV/Excel/PDF格式的資料匯出（租客、物件、應收款項、問題、支出、點交、仲介帶看記錄）

## 6. 假設與限制

- 假設房東已擁有租客的LINE群組，且租客同意接收通知
- 電表度數需由房東或租房管理員手動輸入，暫不支援自動化電表讀取
- 問題反應需由房客主動提交，系統不主動偵測問題
- 支出、點交及仲介帶看資料需由房東、租房管理員或仲介手動輸入或上傳，暫不支援自動化導入
- 系統初期僅支持單一房東及其相關使用者帳號、出租物件、應收款項、問題反應、支出、點交及仲介帶看，未來可擴展至多房東
- 費用計算、應收款項、支出、點交及仲介費用不包含稅務處理，需由房東自行處理

## 7. 未來擴展

- **支付整合**：支援線上繳費功能，自動更新應收款項狀態
- **租客自助服務**：租客可登入系統查看合約、費用明細、出租物件資訊、應收款項狀態、提交/追蹤問題反應及參與點交流程
- **仲介自助服務**：仲介可登入系統管理帶看日程、提交成交資料及查看統計報表
- **多房東支持**：允許多位房東及其相關使用者、出租物件、應收款項、問題反應、支出、點交及仲介帶看共用系統
- **報表功能**：生成年度費用報表、租賃收益分析、出租物件使用率分析、應收款項催繳分析、問題反應統計分析、支出趨勢分析、點交完成率分析及仲介帶看/成交效率分析
