# 房東管理系統需求重新構建

## 1. 系統定位重新定義

### 1.1 核心系統：房東管理系統
- **主要目標**：完整的房屋租賃管理解決方案
- **核心功能**：房屋管理、租客管理、合約管理、收租管理
- **輔助功能**：電費計算、LINE通知、Google Sheets同步

### 1.2 電費計算模組定位
- **功能定位**：租金計算的輔助工具
- **使用場景**：計算每月應收租金時，包含電費部分
- **整合方式**：與合約管理和收租管理緊密整合

## 2. 系統架構重新設計

### 2.1 整體架構

## 3. 核心業務流程重新定義

### 3.1 主要業務流程
1. **房屋管理** → 建立房屋基本資料
2. **租客管理** → 管理租客資訊
3. **合約管理** → 建立租賃合約
4. **月度收租** → 計算並收取租金
5. **電費計算** → 作為租金計算的一部分

### 3.2 電費計算在業務流程中的位置
```
合約建立 → 設定電費計算方式 → 月度收租時自動計算電費 → 生成收租通知
```

## 4. 功能需求重新分類

### 4.1 核心功能 (高優先級)

#### 4.1.1 房屋管理
- **房屋資料管理**：地址、類型、房間數、設施等
- **房屋狀態追蹤**：空置、出租、維修等
- **房屋照片管理**：上傳和管理房屋照片

#### 4.1.2 租客管理
- **租客資料管理**：基本資訊、聯絡方式、緊急聯絡人
- **租客歷史記錄**：租賃歷史、繳費記錄
- **租客狀態管理**：在租、退租、續約等

#### 4.1.3 合約管理
- **合約建立**：租金、押金、起訖日期、電費計算方式
- **合約狀態管理**：生效、到期、終止、續約
- **合約範本管理**：標準合約範本

#### 4.1.4 收租管理
- **月度租金計算**：租金 + 電費 + 其他費用
- **收租通知**：透過LINE發送收租通知
- **繳費記錄**：記錄租客繳費情況
- **逾期管理**：逾期提醒和罰金計算

### 4.2 輔助功能 (中優先級)

#### 4.2.1 電費計算模組
- **電表度數輸入**：支援手動輸入和OCR識別
- **電費計算方式**：
  - 固定電價：每度電固定價格
  - 平均電價：根據前期電費計算平均每度電費
  - 混合電價：私電平均電價 + 公電固定電價
- **電費歷史記錄**：記錄各期電費資料
- **自動計算**：與收租管理整合，自動計算月度電費

#### 4.2.2 其他費用管理
- **管理費**：每月管理費設定和計算
- **清潔費**：清潔費用管理
- **網路費**：網路費用管理
- **其他雜費**：其他費用項目管理

#### 4.2.3 費用計算器
- **月度費用計算**：自動計算每月應收費用
- **費用明細**：詳細的費用分解
- **費用調整**：支援手動調整費用項目

### 4.3 系統功能 (低優先級)

#### 4.3.1 通知服務
- **LINE通知**：收租通知、繳費確認、逾期提醒
- **系統通知**：重要系統事件通知

#### 4.3.2 資料同步
- **Google Sheets同步**：重要資料自動同步
- **資料備份**：定期備份重要資料

#### 4.3.3 報表分析
- **財務報表**：收入、支出、利潤分析
- **收租統計**：收租率、逾期率統計
- **趨勢分析**：租金、電費趨勢分析

## 5. 資料庫設計重新規劃

### 5.1 核心資料表

#### 房屋資料表 (properties)
```sql
CREATE TABLE properties (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(100) NOT NULL, -- 房屋名稱
  address TEXT NOT NULL, -- 地址
  property_type VARCHAR(50), -- 房屋類型
  total_rooms INTEGER, -- 房間數
  total_area DECIMAL(8,2), -- 面積
  monthly_rent DECIMAL(10,2), -- 月租金
  deposit DECIMAL(10,2), -- 押金
  status VARCHAR(20) DEFAULT 'available', -- 狀態：available, rented, maintenance
  description TEXT, -- 描述
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 租客資料表 (tenants)
```sql
CREATE TABLE tenants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(100) NOT NULL, -- 姓名
  email VARCHAR(255), -- 郵箱
  phone VARCHAR(20), -- 電話
  id_number VARCHAR(20), -- 身分證號
  emergency_contact VARCHAR(100), -- 緊急聯絡人
  emergency_phone VARCHAR(20), -- 緊急聯絡電話
  status VARCHAR(20) DEFAULT 'active', -- 狀態：active, inactive
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 合約資料表 (contracts)
```sql
CREATE TABLE contracts (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  property_id UUID REFERENCES properties(id),
  tenant_id UUID REFERENCES tenants(id),
  contract_number VARCHAR(50) UNIQUE, -- 合約編號
  start_date DATE NOT NULL, -- 起租日期
  end_date DATE NOT NULL, -- 到期日期
  monthly_rent DECIMAL(10,2) NOT NULL, -- 月租金
  deposit DECIMAL(10,2) NOT NULL, -- 押金
  electricity_calculation_method VARCHAR(20) DEFAULT 'average_rate', -- 電費計算方式
  fixed_electricity_rate DECIMAL(8,4), -- 固定電價
  management_fee DECIMAL(10,2) DEFAULT 0, -- 管理費
  cleaning_fee DECIMAL(10,2) DEFAULT 0, -- 清潔費
  internet_fee DECIMAL(10,2) DEFAULT 0, -- 網路費
  other_fees JSONB, -- 其他費用
  payment_day INTEGER DEFAULT 1, -- 付款日期
  status VARCHAR(20) DEFAULT 'active', -- 狀態：draft, active, expired, terminated
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 收租記錄表 (rental_records)
```sql
CREATE TABLE rental_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  contract_id UUID REFERENCES contracts(id),
  billing_month DATE NOT NULL, -- 收租月份
  monthly_rent DECIMAL(10,2) NOT NULL, -- 月租金
  electricity_fee DECIMAL(10,2) DEFAULT 0, -- 電費
  management_fee DECIMAL(10,2) DEFAULT 0, -- 管理費
  cleaning_fee DECIMAL(10,2) DEFAULT 0, -- 清潔費
  internet_fee DECIMAL(10,2) DEFAULT 0, -- 網路費
  other_fees DECIMAL(10,2) DEFAULT 0, -- 其他費用
  total_amount DECIMAL(10,2) NOT NULL, -- 總金額
  paid_amount DECIMAL(10,2) DEFAULT 0, -- 已付金額
  payment_date DATE, -- 付款日期
  payment_method VARCHAR(20), -- 付款方式
  status VARCHAR(20) DEFAULT 'pending', -- 狀態：pending, paid, overdue
  notes TEXT, -- 備註
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

### 5.2 輔助資料表

#### 電費記錄表 (electricity_records)
```sql
CREATE TABLE electricity_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  contract_id UUID REFERENCES contracts(id),
  billing_month DATE NOT NULL, -- 收費月份
  meter_reading DECIMAL(10,2) NOT NULL, -- 電表度數
  private_usage DECIMAL(10,2) NOT NULL, -- 私電度數
  public_usage DECIMAL(10,2) NOT NULL, -- 公電度數
  total_usage DECIMAL(10,2) NOT NULL, -- 總用電度數
  electricity_rate DECIMAL(8,4) NOT NULL, -- 每度電費
  total_amount DECIMAL(10,2) NOT NULL, -- 電費總額
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

## 6. 業務流程重新設計

### 6.1 主要業務流程

#### 6.1.1 房屋出租流程
1. **建立房屋資料** → 輸入房屋基本資訊
2. **尋找租客** → 管理租客資料
3. **簽訂合約** → 建立租賃合約
4. **開始收租** → 每月自動計算租金

#### 6.1.2 月度收租流程
1. **系統自動觸發** → 每月固定日期觸發收租計算
2. **計算月度費用** → 租金 + 電費 + 其他費用
3. **發送收租通知** → 透過LINE發送通知
4. **記錄繳費** → 租客繳費後記錄
5. **更新狀態** → 更新收租記錄狀態

#### 6.1.3 電費計算流程
1. **輸入電表度數** → 手動輸入或OCR識別
2. **選擇計算方式** → 根據合約設定選擇計算方式
3. **自動計算電費** → 系統自動計算電費金額
4. **整合到收租** → 電費自動加入月度收租計算

### 6.2 電費計算在系統中的整合

```
合約管理
    ↓
設定電費計算方式
    ↓
月度收租觸發
    ↓
電費計算模組
    ↓
整合到收租記錄
    ↓
生成收租通知
```

## 9. 總結

重新構建後的房東管理系統：

1. **核心定位**：完整的房屋租賃管理系統
2. **電費計算**：作為租金計算的輔助功能
3. **業務流程**：以房屋管理→租客管理→合約管理→收租管理為主軸
4. **功能整合**：電費計算與收租管理緊密整合
5. **系統架構**：以核心業務模組為主，輔助功能為輔

這樣的重新構建更符合實際的房東管理需求，電費計算只是整個系統中的一個重要功能模組，而不是系統的核心。
