# 電費管理系統分析與設計

## 1. Google試算表結構分析

根據 [Google試算表](https://docs.google.com/spreadsheets/d/1IluuW0z3TSCgFEltgo9-A5n74oal1T3fB7-jcn3etm0/edit?usp=sharing) 的內容，我分析出以下結構：

### 1.1 資料結構
- **時間範圍**：113年11~12月 到 114年11~12月
- **房屋單位**：
  - 自強1樓
  - 自強2樓
  - 自強3樓
  - 自強4~5樓
  - 中央MBA
- **資料欄位**：
  - 度數（用電量）
  - 電費（金額）
  - 房客度數加總
  - 房客電費加總
- **計算欄位**：
  - 每度電平均價格
  - 各期加總

### 1.2 業務邏輯分析
1. **電費計算方式**：根據前期平均電費計算每度電費
2. **分攤邏輯**：總電費按房客用電度數比例分攤
3. **歷史追蹤**：記錄各期電費變化趨勢

## 3. 資料庫設計

### 3.1 核心資料表

#### 房屋資料表 (properties)
```sql
CREATE TABLE properties (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR(100) NOT NULL, -- 如：自強1樓
  address TEXT,
  total_units INTEGER DEFAULT 1,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 電費記錄表 (electricity_records)
```sql
CREATE TABLE electricity_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  property_id UUID REFERENCES properties(id),
  period_start DATE NOT NULL, -- 如：2024-01-01
  period_end DATE NOT NULL,   -- 如：2024-02-29
  total_usage DECIMAL(10,2) NOT NULL, -- 總用電度數
  total_amount DECIMAL(10,2) NOT NULL, -- 總電費金額
  tenant_usage DECIMAL(10,2) NOT NULL, -- 房客用電度數
  tenant_amount DECIMAL(10,2) NOT NULL, -- 房客電費金額
  average_rate DECIMAL(8,4), -- 平均每度電費
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 房客資料表 (tenants)
```sql
CREATE TABLE tenants (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  property_id UUID REFERENCES properties(id),
  name VARCHAR(100) NOT NULL,
  email VARCHAR(255),
  phone VARCHAR(20),
  start_date DATE,
  end_date DATE,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

#### 房客用電記錄表 (tenant_usage_records)
```sql
CREATE TABLE tenant_usage_records (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id UUID REFERENCES tenants(id),
  electricity_record_id UUID REFERENCES electricity_records(id),
  usage DECIMAL(10,2) NOT NULL, -- 房客用電度數
  amount DECIMAL(10,2) NOT NULL, -- 房客應付電費
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 4. API設計

### 4.1 電費記錄API

#### 取得電費記錄列表
```http
GET /api/electricity-records
Query Parameters:
- property_id: UUID (可選)
- period_start: YYYY-MM-DD (可選)
- period_end: YYYY-MM-DD (可選)
- page: number (可選)
- limit: number (可選)
```

#### 新增電費記錄
```http
POST /api/electricity-records

      "amount": 1602.5
    }

```

#### 更新電費記錄
```http
PUT /api/electricity-records/:id
Content-Type: application/json

}

Query Parameters:
- months: number (預設6個月)
```

// components/ElectricityCalculator.tsx
interface ElectricityCalculatorProps {
  propertyId: string;
  onCalculate: (result: CalculationResult) => void;
}

const ElectricityCalculator: React.FC<ElectricityCalculatorProps> = ({
  propertyId,
  onCalculate
}) => {
  const [calculationData, setCalculationData] = useState({
    total_usage: 0,
    calculation_method: 'average_rate',
    fixed_rate: 5.0,
    tenant_usage: {}
  });

  const [averageRate, setAverageRate] = useState(0);
  const [calculationResult, setCalculationResult] = useState(null);

  // 取得平均電價
  useEffect(() => {
    fetchAverageRate();
  }, [propertyId]);

  const fetchAverageRate = async () => {
    try {
      const response = await fetch(`/api/electricity-records/${propertyId}/average-rate`);
      const data = await response.json();
      setAverageRate(data.average_rate);
    } catch (error) {
      console.error('取得平均電價失敗:', error);
    }
  };

  const handleCalculate = async () => {
    try {
      const response = await fetch('/api/electricity-calculator', {
        method: 'POST',
        headers: {
          'Content-Type': 'application/json',
        },
        body: JSON.stringify({
          ...calculationData,
          property_id: propertyId
        }),
      });
      
      const result = await response.json();
      setCalculationResult(result);
      onCalculate(result);
    } catch (error) {
      console.error('計算失敗:', error);
    }
  };

  return (
    <div className="bg-white p-6 rounded-lg shadow">
      <h3 className="text-lg font-medium text-gray-900 mb-4">

      </h3>

## 6. Google Sheets同步服務

### 6.1 同步服務實現

```javascript
// services/googleSheetsSyncService.js
const { google } = require('googleapis');

class GoogleSheetsSyncService {
  constructor() {
    this.sheets = google.sheets({ version: 'v4', auth: this.auth });
    this.spreadsheetId = process.env.GOOGLE_SHEETS_ID;
  }

  // 從Google Sheets讀取資料
  async readFromSheets() {
    try {
      const response = await this.sheets.spreadsheets.values.get({
        spreadsheetId: this.spreadsheetId,
        range: 'A1:Z100', // 根據實際範圍調整
      });

      return this.parseSheetData(response.data.values);
    } catch (error) {
      console.error('讀取Google Sheets失敗:', error);
      throw error;
    }
  }

  // 解析試算表資料
  parseSheetData(values) {
    const records = [];
    
    // 跳過標題行
    for (let i = 3; i < values.length; i++) {
      const row = values[i];
      if (!row[0] || row[0] === '加總') continue;
      
      // 解析每一期的資料
      for (let j = 1; j < row.length; j += 4) {
        if (row[j] && row[j + 1]) {
          records.push({
            property_name: row[0],
            period: this.getPeriodFromColumn(j),
            total_usage: parseFloat(row[j]) || 0,
            total_amount: parseFloat(row[j + 1]) || 0,
            tenant_usage: parseFloat(row[j + 2]) || 0,
            tenant_amount: parseFloat(row[j + 3]) || 0
          });
        }
      }
    }
    
    return records;
  }

  // 更新Google Sheets
  async updateSheets(data) {
    try {
      const values = this.formatDataForSheets(data);
      
      await this.sheets.spreadsheets.values.update({
        spreadsheetId: this.spreadsheetId,
        range: 'A4:Z100', // 根據實際範圍調整
        valueInputOption: 'RAW',
        resource: { values }
      });
      
      console.log('Google Sheets更新成功');
    } catch (error) {
      console.error('更新Google Sheets失敗:', error);
      throw error;
    }
  }

  // 格式化資料為試算表格式
  formatDataForSheets(data) {
    // 將資料轉換為試算表格式
    return data.map(record => [
      record.property_name,
      record.total_usage,
      record.total_amount,
      record.tenant_usage,
      record.tenant_amount
    ]);
  }
}

module.exports = GoogleSheetsSyncService;
```
