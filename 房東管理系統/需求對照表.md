# 需求對照表

## 原始需求想法 vs 詳細規格對照

| 原始需求想法 | 對應需求編號 | 詳細規格描述 | 實現方式 |
|-------------|-------------|-------------|----------|
| **1. 輸入電表度數，算出電費** | REQ-001-01 | 電表度數輸入功能 | 手動輸入 + OCR拍照識別 |
| **1.1 固定電價** | REQ-001-02-01 | 固定電價計算 | 電費 = (私電+公電) × 固定單價 |
| **1.2 依前期平均電費算出每度電費** | REQ-001-02-02 | 平均電價計算 | 電費 = (私電+公電) × 平均每度電費 |
| **1.3 混合電價計算** | REQ-001-02-03 | 混合電價計算 | 電費 = 私電×平均電價 + 公電×固定電價 |
| **2. 租金加上電費算出本月要收的費用** | REQ-003-01 | 月度費用計算 | 月度應收費用 = 月租金 + 電費 + 其他費用 |
| **2.1 要先建立合約** | REQ-002-01 | 合約建立功能 | 包含租金、押金、起訖日、電費計算方式等 |
| **3. 輸入前期電費，算出平均每度電費** | REQ-001-03 | 前期電費輸入與平均計算 | 平均每度電費 = Σ電費總額 ÷ Σ總用電度數 |
| **4. 透過賴發出收租通知** | REQ-004-01 | 收租通知功能 | LINE自動發送收租通知 |
| **5. 房客繳租金後記錄，並發出已收到租金到賴群** | REQ-004-02 | 繳費確認通知 | 繳費後自動發送確認通知到LINE群組 |
| **6. 房屋管理者有1到多位，相同權限** | REQ-005-01 | 多管理者支援 | 支援多位管理者，權限平等 |
| **7. 資料儲存至Google試算表** | REQ-006-01 | 資料同步功能 | 自動同步至Google Sheets |
